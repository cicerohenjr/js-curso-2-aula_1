# 📘 JavaScript — Funções, Listas e Interação com HTML

Este repositório reúne exercícios práticos desenvolvidos durante o curso **"Lógica de programação: explore funções e listas"**, da Alura, como parte da Trilha DevOps do Santander Open Academy.

O objetivo é praticar os fundamentos da programação com JavaScript, aplicando conceitos de funções, cálculos, listas (*arrays*) e interação com elementos HTML.

## 📂 Conteúdo do repositório

### 1. Interagindo com HTML via JavaScript

Pasta: `desafio-interagindo-html/`

Reúne cinco desafios que demonstram como conectar funções JavaScript a botões HTML e interagir com os elementos da página.

**Principais conceitos:** manipulação do DOM, eventos de clique, funções, mensagens com `alert()` e `prompt()` e validação de entradas.

### 2. Funções e cálculos

Pasta: `desafios-funcoes-calculos/`

Apresenta seis desafios com funções voltadas a cálculos matemáticos, como IMC, fatorial, conversão de dólar para real com cotação fixa, área e perímetro de figuras geométricas e tabuada.

**Principais conceitos:** parâmetros, retorno de valores com `return`, operações matemáticas e estruturas de repetição com `for`.

### 3. Funções em JavaScript

Pasta: `desafios-funcoes/`

Contém seis desafios para praticar a criação e a utilização de funções, incluindo saudações, cálculo do dobro, média de números, comparação de valores e cálculo do quadrado.

**Principais conceitos:** declaração e chamada de funções, parâmetros, retorno de valores e operador ternário.

### 4. Listas (*Arrays*) em JavaScript

Pasta: `desafios-listas/`

Reúne seis desafios sobre criação e manipulação básica de listas, incluindo listas vazias ou preenchidas, adição de elementos e acesso a itens específicos.

**Principais conceitos:** declaração de arrays, método `push()`, índices e acesso aos elementos de uma lista.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura das páginas;
- **CSS3:** apresentação visual;
- **JavaScript:** lógica de programação e interatividade.

## 📚 Aprendizados

As atividades contribuem para desenvolver conhecimentos fundamentais de programação, como:

- Criação e reutilização de funções;
- Manipulação de elementos HTML;
- Utilização de variáveis, parâmetros e retornos;
- Realização de cálculos matemáticos;
- Criação e manipulação de arrays;
- Interação com o usuário e validação de entradas.
